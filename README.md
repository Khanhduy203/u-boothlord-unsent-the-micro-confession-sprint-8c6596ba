Entry for the [Unsent: The Micro-Confession Sprint](https://make.fun/bounty/u-boothlord-unsent-the-micro-confession-sprint-8c6596ba) bounty on make.fun.

The program writes a single two-part micro-confession to `entry.txt`: a `To:` line naming who it was meant for, and the unsent message itself, exactly as it was typed — a confession kept in drafts because saying it out loud would have meant admitting something kept private for years.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
cat /tmp/out/entry.txt
```

Requires Node 22 or later. No dependencies, no network.
